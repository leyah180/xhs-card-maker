# 小红书包包 · 卡片排版工具

小红书图文卡片排版工具。基于 Canvas 渲染，纯前端，一个 HTML 文件就能用。

## 功能

- **文本排版**：支持标题、引用、加粗、斜体、彩色文字、文字底色
- **图片管理**：上传图片，通过 `[[image:id]]` 插入到内容中
- **自由拖拽 + 缩放**：双击图片缩略图切换"自由模式"，可在预览区任意拖拽位置 + 右下角缩放手柄调整大小
- **页边距调节**：窄/标准/宽/较宽 四档，解决内容拥挤问题
- **布局风格**：简洁模式（无头像栏，更干净）和标准模式（带头像栏）
- **水印功能**：自定义文字 + 四角位置 + 透明度调节
- **多套主题**：清爽白、暖阳橙、冰蓝紫、森林绿、玫瑰粉、深空蓝、墨黑
- **字体设置**：中英文分别选择字体（系统/宋体/楷体/黑体/衬线/圆体）
- **卡片设置**：字号、行距、文字颜色、背景色、强调色、图片大小
- **批量下载**：导出 PNG 单张下载，或 JSZip 打包下载全部
- **AI 辅助**：内置 AI 优化入口（支持 Chrome 内置 AI 和手动粘贴到 GPT）
- **自动保存**：输入内容自动保存到浏览器本地，刷新不丢失

## 使用方法

### 方式一：本地打开

直接双击 `index.html` 用浏览器打开，不需要任何服务器。

### 方式二：GitHub Pages 部署

```bash
# 1. 在 GitHub 上创建仓库
# 2. 把 index.html 推上去
git init
git add index.html
git commit -m "init"
git remote add origin https://github.com/你的用户名/仓库名.git
git push -u origin main

# 3. 在仓库 Settings → Pages 中：
#    Source: Deploy from a branch
#    Branch: main, / (root)
#    点 Save
# 4. 等几分钟，访问 https://你的用户名.github.io/仓库名
```

### 基本操作

```
1. 在左侧编辑区写内容
2. 用工具栏按钮添加格式（B=加粗、I=斜体、H1/H2=标题、❝=引用）
3. 选中文字后点颜色按钮，自动生成彩色/底色标记
4. 上传图片，点击缩略图插入到光标位置
5. 双击缩略图切换"自由拖拽模式" — 可在预览区直接拖图片
6. 在预览区点击图片右上角"取消自由"恢复流式排版
7. 右侧预览自动刷新，点击"下载"导出单张
8. 点"批量下载"打包全部图片
```

### 支持的格式

| 格式 | 语法 | 示例 |
|------|------|------|
| 大标题 | `# 标题` | `# 今天吃什么` |
| 小标题 | `## 标题` | `## 早餐推荐` |
| 引用 | `> 内容` | `> 重要提示` |
| 加粗 | `**文字**` | `**重点**` |
| 斜体 | `*文字*` | `*备注*` |
| 彩色文字 | `{{color:#ff0000\|文字}}` | `{{color:#e94e77\|粉色字}}` |
| 文字底色 | `{{bg:#ffd60a\|文字}}` | `{{bg:#ffd60a\|高亮}}` |
| 插入图片 | `[[image:id]]` | `[[image:iabc123]]` |

## 技术说明

- 纯前端，无后端依赖
- Canvas 2D 渲染卡片
- 本地存储保存编辑状态
- JSZip（CDN 加载）批量打包
- 图片通过 Data URL 存储（注意：大图片会影响性能）
